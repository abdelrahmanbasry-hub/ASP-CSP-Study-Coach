# ASP + CSP // Coach

An original dual-track adaptive study coach for the current BCSP ASP11 and
CSP11 public blueprints. It provides weighted 20-question drills, 200-question
simulations, confidence and pace tracking, item-response difficulty adjustment,
weak-domain prioritization, delayed block rationales, and local progress
persistence.

## Prerequisites

- Node.js `>=22.13.0`

## Quick Start

```bash
pnpm install
pnpm dev
pnpm build
pnpm test
```

Progress is stored in the browser. All practice items and rationales are
independently authored; the product is not affiliated with or endorsed by BCSP
or Pocket Prep. The 80% stability rule is a coaching threshold, not an official
BCSP passing score.
